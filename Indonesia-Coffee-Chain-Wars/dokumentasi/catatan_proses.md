# Catatan Proses

1. Memuat workbook Excel dan memeriksa sheet `Dataset`, `Data_Dictionary`, dan `Business_Analysis`.
2. Memeriksa ukuran data, tipe data, nilai kosong, duplikasi seluruh baris, dan duplikasi ID transaksi.
3. Memeriksa konsistensi rumus estimasi pendapatan: jumlah cup dikalikan harga bersih.
4. Menggunakan agregasi total dan rata-rata untuk membandingkan brand, kota, metode pemesanan, format gerai, segmen pelanggan, tier loyalitas, dan pemicu perpindahan brand.
5. Menyiapkan KPI dan visualisasi di Power BI.

Catatan: tidak ada baris yang dihapus karena hasil pemeriksaan tidak menemukan missing value maupun duplikasi. Simpan file PBIX dan screenshot dashboard hasil akhir ke folder yang disediakan.
